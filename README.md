## 🎹 Featured Project

### [Piano Lens](https://github.com/MariaMenshchikova/Piano-Lens)

A digital piano practice coach that compares a performance with a musical score and provides score-aware feedback.

It combines:

* Python
* Streamlit
* audio transcription
* MusicXML / MIDI processing
* PDF optical music recognition
* note alignment
* timing and expressive analysis
